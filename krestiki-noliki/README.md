# Крестики-нолики в пиратском море

Пиратская браузерная игра: капитан сражается со штурманом за три клетки подряд.

## Запуск

Откройте `index.html` в браузере. Дополнительные зависимости не нужны.

## Возможности

- поле 3x3 и подсветка победной линии;
- режим дуэли вдвоем;
- режим игры против компьютера;
- два уровня штурмана: «Юнга» и «Морской волк»;
- счет капитана и штурмана;
- адаптивная верстка для телефона и компьютера.
